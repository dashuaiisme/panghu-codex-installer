# Codex 三模式互切真机验证清单

日期：2026-07-03
用途：这类"写配置给 Codex 用"的代码，单元测试只能证明我们写的文件格式对，不能证明 Codex 真认。本清单让你在真实机器上照着点一遍，确认三模式来回切都生效、且不丢 ChatGPT 登录态。约 10 分钟。

## 背景：三种模式各写什么

| 模式 | 客户端按钮 | 写入内容 | 消耗 | 需要 ChatGPT 登录 |
| --- | --- | --- | --- | --- |
| 普通模式（direct_api） | 开始部署与配置 / 仅写入配置 | `config.toml` 写 panghuAI provider；`auth.json` 写 OPENAI_API_KEY=胖虎Key | 胖虎额度 | 否 |
| 双态模式（dual_state） | 双态混合模式配置 | `config.toml` 写 panghuAI provider + experimental_bearer_token；保留 auth.json 里的 ChatGPT 登录态 | 胖虎额度 | 是（保留） |
| 官方直登（official_chatgpt） | 官方直登配置 | 写官方 openai provider；不写胖虎 Key；保留 ChatGPT 登录态 | ChatGPT 账号额度 | 是 |

关键机制：每次切换前，客户端会把当前配置存进 `~/.codex/panghu_modes/<模式名>/` 快照。切回某模式时可从快照恢复，避免 ChatGPT 登录态被来回切没。

## 更新（2026-07-03）：现在全程一键，不用手动改/看配置文件

在"配置Agent"模块第 5 步新增了"Codex 模式一键切换"面板：
- 三个大按钮：**切到普通模式 / 切到双态模式 / 切到官方直登** —— 点一下自动改配置，不用手动编辑任何文件。
- **检测当前模式** 按钮 —— 点一下直接告诉你现在是哪种模式、ChatGPT 登录态是否保留、网关是否正常。不用再打开 config.toml / auth.json 核对。

所以下面的验证步骤，凡是"打开 xx 文件确认 xx"的，现在都可以改成**点"检测当前模式"看结果**。测试流程变成：点切换 → 退出重开 Codex → 发中文测 → 点检测确认。

## 准备

1. 装好 Codex CLI，先用你自己的 ChatGPT 账号 `codex login` 登录一次（为了验证"双态/官方直登不丢登录态"）。
2. 打开胖虎AI客户端，登录、填好胖虎AI API Key。
3. 记住：**每次点完切换，必须完全退出 Codex 再重新打开**，否则不生效。

## 验证步骤（每步做完打勾）

### A. 普通模式（消耗胖虎额度，不需要 ChatGPT）
- [ ] A1 面板点"切到普通模式"
- [ ] A2 点"检测当前模式"，显示"普通模式（走胖虎额度）"、网关正常
- [ ] A3 完全退出 Codex，重开，发一句中文："请回复：胖虎AI配置验证成功"
- [ ] A4 Codex 正常中文回复 → 普通模式生效 ✅

### B. 切到双态模式（保留 ChatGPT 登录态，仍消耗胖虎额度）
- [ ] B1 面板点"切到双态模式"
- [ ] B2 点"检测当前模式"，显示"双态模式"、**ChatGPT 登录态：保留 ✓**
- [ ] B3 完全退出 Codex，重开，发中文测试句
- [ ] B4 能中文回复，且模型消耗走胖虎（在胖虎网站用量页能看到消耗）→ 双态生效 ✅

### C. 切到官方直登（消耗 ChatGPT 账号额度，不写胖虎 Key）
- [ ] C1 面板点"切到官方直登"
- [ ] C2 点"检测当前模式"，显示"官方直登"、**ChatGPT 登录态：保留 ✓**
- [ ] C3 完全退出 Codex，重开，发中文测试句
- [ ] C4 能回复（走你自己的 ChatGPT 账号）→ 官方直登生效 ✅

### D. 切回普通模式（关键：验证来回切不出错）
- [ ] D1 面板点"切到普通模式"
- [ ] D2 完全退出 Codex，重开，发中文测试句 → 能回复 ✅
- [ ] D3 再点"切到双态模式" → 点"检测当前模式"，确认 **ChatGPT 登录态经过这一圈来回切之后依然显示"保留 ✓"** ✅

### E. 快照验证（可选）
- [ ] E1 打开 `~/.codex/panghu_modes/`，确认有 `direct_api/`、`dual_state/`、`official_chatgpt/` 子目录，各含 config/auth 快照
- [ ] E2 客户端"恢复备份快照"能列出并回滚

## 判定

- A~D 全部打勾 = 三模式互切功能真机通过，可写入 FINAL_REPORT 的"已验证"。
- 任一步失败，把以下信息发给 Claude：
  - 哪一步（如 B3）
  - 该步涉及的 `config.toml` 或 `auth.json` 内容（**先把 Key、token 打码**再发）
  - Codex 报错原文
- 常见问题：切完没退出 Codex 就测（无效，必须完全退出重开）；auth.json 里 ChatGPT 登录态消失（说明快照恢复有 bug，重点排查）。
