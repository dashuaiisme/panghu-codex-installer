# 胖虎AI客户端唯一产品手册

最后更新：2026-06-29

## 1. 本手册的地位

本文件是“胖虎AI客户端”的唯一产品级权威手册。

用途：

- 给 Codex / 子 Agent 做 UI、代码、文案、验收时的统一依据。
- 给后续维护窗口明确哪些信息以产品口径为准，哪些信息只属于技术维护说明。

规则：

- 涉及产品结构、界面层级、客户可见文案、交付边界、验收标准时，以本手册为准。
- 涉及接口、构建、签名、打包、发布、脚本、目录和技术限制时，以 `docs/TECHNICAL_MAINTENANCE_MANUAL.md` 为准。
- `README.md` 只做仓库入口摘要，不再承担分散的产品定义职责。
- `legacy/` 目录不作为当前产品判断依据。

## 2. 产品定位

“胖虎AI客户端”是面向买家和新手用户的一站式 AI 客户端服务工具，不是脚本工具，也不是胖虎AI网站控制台的替代页。它把客户使用 AI 时常见的下载、账号、API、中转站、充值购买、会员服务、手机号/短信接码、连接通讯软件和交付验收卡点集中到一个登录后的客户端里处理。

统一产品主线：

- 胖虎AI客户端是主产品、客户入口和顶部业务容器。
- 胖虎AI中转站、手机接码、Plus 充值 / Plus 订阅、连接通讯软件、代理中心都作为胖虎AI客户端内的功能区、分支服务或服务入口被承接。
- 胖虎AI中转站不是整个平台后台，也不是桌面客户端后台；它在客户端体系里对应 API 网关、API Token、余额扣费、模型调用、用量记录、模型价格、网关侧充值记账和必要的 token 返佣。
- 独立胖虎AI后台管理系统才是账号、订单、支付、权益、代理、服务目录、运营配置和跨服务编排的管理后台。

它的职责是：

1. 让客户先统一登录胖虎AI账号。
2. 登录后按账号权益展示客户可使用的模块、Agent、服务和交付状态。
3. 在“配置Agent”模块内完成 API Key 创建/填写、环境检测、Agent 选择、安装、配置写入、启动检测、最小中文对话验收和功能验收矩阵。
4. 在“胖虎AI网站”模块内承载控制台、充值购买、API Key、推广返佣等网站能力的内置浏览器入口。
5. 在“配置Agent -> 连接通讯软件”内承载连接通讯软件独立增值交付：把已可用 Agent 接入 QQ、微信、飞书、钉钉、企业微信等通讯软件或办公协同通道。
6. 在“增值业务”模块内展示服务端下发的 Plus 订阅、账号服务、手机卡/云号码、手机号/短信接码、连接通讯软件和其他可用业务入口、权益状态和交付状态。
7. 在“代理中心”模块内承载本工具独立代理业务：代理总览、下游客户、token 返佣、下游付费激活返佣、付费安装 Agent 返佣、工具代理后端和代理规则相关入口。

它不负责：

- 取代胖虎AI官网完整购买站。
- 把胖虎AI中转站、支付、钱包、控制台、后台管理逻辑整个搬进桌面端。
- 把胖虎AI中转站写成胖虎AI平台主后台、胖虎AI客户端后台或整个平台后台。
- 在本地硬编码注册、邀请码、商品价格、购买次数、返佣比例、套餐规则、设备数或有效期。
- 在登录前提供身份分流入口。
- 在本地实现代理中心的商业规则。代理身份只来自登录后的账号权益，token 返佣、下游付费激活返佣、付费安装 Agent 返佣、代理等级、结算规则和数据都由服务端与代理后端控制。
- 在本地硬编码 Plus 订阅、GPT 会员代充、接码平台、账号服务或其他增值业务的价格、库存、履约承诺、有效期、设备数、次数或上架状态。
- 在本地保存或处理短信内容、接码设备 token、Plus Session Token、激活服务密钥、支付密钥或真实履约密钥。

## 3. 当前产品边界

当前桌面端允许：

- 登录胖虎AI账号。
- 向服务端申请部署授权。
- 显示商业版账号、版本标识、剩余次数、有效期、设备数、公共域名。
- 根据服务端数据展示账号、权益、代理身份和交付摘要。
- 安装与配置已接入完整配置链路的 Agent：Codex、ClaudeCode（CC）、OpenClaw、Hermes、Gemini / agy（Google Antigravity）。
- 用 Agent 五维状态做交付跟踪：安装、启动、对话、验收、交付；五个 Agent 使用同一验收矩阵门控。
- 在登录后的内置浏览器中打开胖虎AI网站的控制台、推广返佣、创建 Key、充值购买、代理中心和增值业务入口。

当前桌面端不承诺：

- 在工具内完整复刻网页购买中心。
- 在未经过真实网页验收前，承诺注册、充值、支付、钱包管理、API Key 创建全流程已经闭环。
- 把未通过最小中文对话验收的 ClaudeCode、OpenClaw、Hermes 或 Gemini / agy 链路包装成已完整交付。
- 离线计算价格、购买次数、token 返佣、激活返佣、安装返佣、代理等级或课程权益。
- 把连接通讯软件当成基础 Agent 配置的一部分统一验收、统一扣费或统一失败。

当前内置浏览器口径：

- 桌面端正式客户界面固定为 WebView UI，客户包必须内置 pywebview 和 `src/ui/index.html` 对应资源。
- 桌面端可以在软件内 WebView 打开胖虎AI网站服务端页面。
- 控制台、推广返佣、创建 Key、充值购买、代理中心等业务仍由 `https://aitokenapi.cc` 服务端页面完成。
- 如果正式客户包缺少 `pywebview` 或 WebView UI 资源，视为打包/启动失败，不得回退到旧 Tkinter 业务界面；如果网页运行环境阻止嵌入，客户站点入口必须明确提示“内置浏览器未完成/不可用”，不得自动打开系统浏览器，也不得说已经完成内置闭环。
- 如果后续接入桌面内购买能力，仍必须走服务端控制，不得本地硬编码商品规则。

## 4. 产品结构与设计自由度

登录后的主界面必须保留以下产品能力，但不再要求固定为六块式排版。Gemini / agy 可以按 `gemini-style-frontend-design` 自由重组布局、导航、面板、抽屉、命令区、状态区和日志区，只要客户能清楚完成对应流程：

1. 品牌与当前账号识别
2. 一级业务入口
3. 当前任务或模块内的步骤导航
4. 主要操作工作区
5. 账号 / 权益 / Agent 交付状态
6. 可复制的执行日志、诊断或最近活动

一级业务入口必须覆盖：

1. 配置Agent
2. 胖虎AI网站
3. 增值业务
4. 代理中心

“代理中心”是本工具登录后的独立代理业务模块，不能只等同于胖虎AI网站的推广返佣页；推广返佣页只覆盖网站侧 token 返佣入口，本模块还必须预留下游客户付费激活返佣、付费安装 Agent 返佣和工具代理后端合同。

代理业务的经营配置入口不在桌面客户端内。胖虎AI管理员账号必须在胖虎AI管理员后台看到“代理业务管理”，用于维护代理产品介绍、五级费用设置、返佣规则、代理审核、下游客户、佣金账本、结算提现、推广素材和风控冻结。桌面端只展示服务端下发的 `agent_center` 快照、内置浏览器入口和客户可理解的状态，不计算代理费用、等级、返佣比例或结算结果。

公开招商页固定为 `/agent/join`，服务端必须讲清楚“卖什么、怎么赚钱、费用多少、适合谁、如何结算、风险边界、立即申请”。桌面端可提供“招商介绍”“工具代理后端”“代理规则”等入口，但所有内容由服务端维护；客户端不得把招商文案、价格、返佣比例或审核规则写死。

主工作区按业务入口切换，但具体排版由 Gemini / agy 决定：

- 配置Agent：必须让客户明确当前步骤、下一步和验收状态；可以使用单步骤卡片、命令面板、分屏流程、抽屉或其他 Gemini 判断更好的布局。
- 胖虎AI网站：显示内置浏览器，打开胖虎AI网站的控制台、Key、充值、推广返佣等服务端页面。
- 增值业务：显示服务端下发的业务入口卡片、内置浏览器或占位状态。其中“接码服务”固定作为“接码控制台”入口，指向胖虎AI现有域名的 `sim` 子域名，承接手机号接码控制中心网页；“Plus 订阅”入口关联 Plus session.脚本工具，但购买、激活码发放、Session Token 处理和履约状态必须由服务端及 Plus 执行器完成。
- 代理中心：显示内置浏览器、代理后端入口或服务端下发的代理业务卡片，承接代理总览、下游客户、token 返佣、激活返佣、安装返佣、工具代理后端和代理规则。

禁止回退成：

- 所有步骤堆成一整页
- 未登录时先展示完整主控制台
- 用固定 10 步向导替代完整业务入口
- 登录前身份分流入口
- 账号 / 权益 / Agent 交付状态完全消失
- 黑色运维终端式大顶栏
- 花哨装饰稿或玻璃拟态风格

## 5. 登录门禁规则

未登录前必须是“登录闸口”，不是主控制台。

未登录页允许显示：

- 品牌区
- 账号密码输入
- 新账号注册用的邀请码 / 代理邀请链接输入；该字段只用于打开胖虎AI网站注册页并带上 `invite` 参数，不在本地绑定代理身份
- “自动登录”和“记住密码”勾选项；自动登录必须依赖用户已勾选记住密码并存在可解密的本机密码记录
- 账号输入框下拉历史账号；每个账号后方必须提供删除入口，用于清除该账号提示、加密密码记录、自动登录标记和可匹配的本机买家会话
- 最少说明
- 注册入口
- 打开胖虎AI网站注册页的入口

未登录页禁止显示：

- 身份分流入口
- 左侧模块子导航
- 顶部一级模块导航
- 右侧账号、权益和 Agent 状态
- 完整部署控制台
- 完整执行日志

登录后的身份规则：

- 买家、代理、课程用户、增值业务用户都先走同一个胖虎AI账号登录。
- 客户没有账号时，登录闸口允许先填写代理邀请码或代理邀请链接，再打开胖虎AI网站注册页；最终注册、绑定上级和防覆盖规则由服务端完成。
- 代理身份只作为登录后的账号权益展示。
- 代理相关入口放在顶部“代理中心”模块内承接。
- 本地客户端不得自行判断、计算或写死 token 返佣、激活返佣、安装返佣、代理等级、邀请奖励、价格或次数。
- 本地客户端不得提供代操作会话、第三方账号代登录或本地代理操作者身份。

## 6. 视觉方向

当前视觉主方向改为：

- 中文界面
- 由 Gemini / agy 按 `gemini-style-frontend-design` 技能文件重新设计；实际呈现以它输出的设计方案、组件系统和截图验收为准
- 允许深色高级、Gemini AI 产品语言、柔和多色 AI aura、Material 3 精密组件和更强的 AI command surface
- 不再强制浅色企业控制台、苹果风钛金白或浅蓝后台主色；旧浅色方案不再作为审美约束
- 必须保留“客户交付软件控制台”的业务密度、清晰层级和客服可解释的引导
- 颜色、深浅、圆角、阴影、动效和状态反馈应形成统一 token / component system，不能临时拼样式

不是以下风格：

- 黑色终端
- 概念稿大装饰条
- 低质玻璃拟态
- 无状态含义的强渐变堆叠
- 暖橙棕客服向导
- 运维脚本面板
- 一页式营销页

## 8. 品牌 / 账号 / 工具入口能力规则

以下信息必须在 Gemini / agy 选择的界面结构中清晰可见或可快速展开，不强制放在传统 TopBar：

- 品牌识别
- 产品名
- 当前账号
- 商业版本标识
- 剩余次数
- 检查更新入口
- 设置入口；设置菜单只保留“切换账号”“切换主题”“退出当前账号”

品牌 / 账号区域不应该承担：

- 大段说明
- 复杂商业规则解释
- 一长串技术字段

视觉要求：

- 左右对齐稳定
- 不露头、不塌陷
- 普通窗口和全屏都保持清晰的视觉秩序
- 不要廉价拼贴感

## 9. 一级业务入口规则

一级业务入口承担产品主信息架构，但不强制放在顶部，也不强制与 TopBar 结合。Gemini / agy 可以使用顶部导航、侧栏、命令面板、主页入口、抽屉或其他更合适的形式；不得退回旧的单一 10 步向导作为全局结构。

一级模块固定为：

1. 配置Agent
2. 胖虎AI网站
3. 增值业务
4. 代理中心

一级模块职责：

- 配置Agent：客户交付主链路，负责已接入 Agent 的安装、配置、验证和交付矩阵；五个 Agent（含 Gemini / agy）都按完整配置链路处理。
- 胖虎AI网站：承载注册、邀请码、创建 Key、充值购买、代理中心、账号中心等网站服务端页面。
- 增值业务：展示客户可购买或已开通的增值服务入口，具体规则来自服务端。
- 代理中心：承载代理总览、下游客户、token 返佣、下游付费激活返佣、付费安装 Agent 返佣、工具代理后端和代理规则等入口，具体规则来自服务端。

入口规则：

- 当前模块要有明确选中态。
- 模块切换时，任务流程、主工作区和状态摘要要同步切换。
- 不允许把代理身份提前做成登录前入口。
- 不允许把网站里的购买、充值、邀请码、返佣规则复制到本地硬编码。

## 10. 模块内步骤定位规则

模块内步骤定位只负责当前业务入口内的流程提示和状态提示，不强制放在左侧，也不强制使用传统子导航。Gemini / agy 可以使用侧栏、顶部步骤条、时间线、命令面板、抽屉、分组卡片或其他更合适的形式。不得用全局固定 10 步替代完整业务入口。

“配置Agent”模块的子导航建议为：

1. 创建或填写 API Key
2. 检测系统环境
3. 选择 Agent
4. 执行安装
5. 写入配置
6. 启动检测
7. 最小中文对话验收
8. 功能验收矩阵
9. 基础交付验收
10. 连接通讯软件
11. 连接通讯软件交付验收

“胖虎AI网站”模块的子导航建议为：

1. 控制台
2. 创建 API Key
3. 充值购买
4. 推广返佣

“增值业务”模块的子导航由服务端下发或显示预留分类，不在本地硬编码价格、次数或套餐规则。

建议的增值业务分类包括 Plus 订阅、国外手机卡 / 云号码、接码控制台和连接通讯软件销售介绍。Plus 订阅关联 Plus session.脚本工具，接码控制台和手机卡 / 云号码关联手机号接码控制中心；客户端只做入口、会话桥接和状态摘要展示。

“代理中心”模块的子导航建议为：

1. 代理总览
2. 下游客户
3. token 返佣
4. 激活返佣
5. 安装返佣
6. 工具代理后端
7. 招商介绍
8. 代理规则

模块内步骤定位职责：

- 只负责当前模块内定位和状态提示
- 不承担长说明
- 不替代一级业务入口

## 11. 中间主工作区规则

主操作区域必须根据当前业务入口展示对应能力，例如任务流程、内置浏览器、服务端业务入口、占位状态或 Gemini / agy 认为更合适的组合布局。

规则：

- 配置Agent模块必须让当前任务层级清晰；Gemini / agy 可选择单步骤卡片、分屏流程、命令面板、时间线或其他更合适的呈现方式。
- 当前步骤标题要明确。
- 说明要口语但专业。
- 告诉客户“现在做什么、做完看哪里”。
- 不要把所有信息都堆在一页首屏
- 胖虎AI网站模块优先使用内置浏览器打开服务端页面。
- 增值业务和代理中心在内容未上线前可以显示清晰占位，但必须说明由服务端或网站接入。
- Plus 订阅、国外手机卡 / 云号码和接码控制台都必须走服务端目录和对应服务页。客户端不得把 Plus 激活码、Session Token、短信内容、号码分配、库存、套餐规则或真实履约状态写入本地逻辑。
- 代理中心内容上线后，桌面端优先使用服务端 `agent_center` 快照展示：代理状态、当前等级、邀请入口、招商介绍入口、工具代理后端入口、代理规则入口、下游客户数、token 返佣、激活返佣、安装返佣、可结算、待结算和冻结金额。
- 连接通讯软件主入口固定在“配置Agent -> 连接通讯软件”。增值业务模块可以展示销售卡片、价格说明和服务介绍，但正式配置、检测和验收必须回到该入口；代理中心不得作为连接通讯软件入口。
- 连接通讯软件与基础 Agent 配置有业务顺序建议，但不能做成硬绑定解锁。客户本机原本已有可用 Agent、以前已经配置过 Agent、或由人工服务确认可用时，允许直接进入连接通讯软件的已有 Agent 检测、选择、通道配置和单独验收链路。

必须走内置浏览器 / 网站服务端的事项：

- 注册账号
- 查看推广返佣 / 邀请入口
- 创建 API Key
- 充值购买
- 订阅、套餐、增值业务购买
- 代理中心、token 返佣、激活返佣、安装返佣、邀请奖励和代理权益查看
- 代理招募页 `/agent/join`
- 代理结算申请和风控状态查看

本地步骤卡不得写死这些事项的商业规则，只能提供入口、状态提示和客服可理解的引导。

## 12. 账号 / 权益 / 交付状态能力规则

账号 / 权益 / 交付状态必须长期承担“账号确认 + 权益摘要 + 交付结论”职责，但不强制固定在右侧面板。Gemini / agy 可以把它设计为顶部状态、侧边栏、浮层、抽屉、状态卡、命令区附属面板或其他更合适的结构。

首屏优先级：

1. 当前账号和登录状态
2. 当前权益摘要
3. 当前交付结论
4. Agent 交付状态
5. 当前模块相关状态

账号 / 权益摘要可以展示：

- 当前账号（脱敏）
- 商业版本标识
- 账号角色 / 权益标签
- 代理身份状态（如果服务端返回）
- 代理业务摘要（如果服务端返回）：下游客户数、token 返佣、激活返佣、安装返佣、待结算/已结算状态
- 剩余次数或额度（如果服务端返回）
- 有效期
- 设备数
- 当前公共域名 `https://aitokenapi.cc`

账号 / 权益 / 交付状态区域禁止：

- 本地计算商品价格
- 本地计算购买次数
- 本地计算返佣比例
- 本地计算代理等级
- 本地计算 token 返佣、激活返佣、安装返佣或下游客户归因
- 本地写死套餐权益
- 把未登录用户展示成已授权用户

完整配置交付验收对象：

- Codex
- ClaudeCode（CC）
- OpenClaw
- Hermes

每个已接入 Agent 状态必须拆成五个维度：

- 安装状态
- 启动状态
- 对话状态
- 验收状态
- 交付状态

禁止把五个维度合并成一个“总状态”替代展示。

Gemini / agy（Google Antigravity）已接入完整配置链路：写入 `~/.gemini/.env` 的 GOOGLE_GEMINI_BASE_URL、GEMINI_API_KEY、GEMINI_MODEL，走胖虎AI网关 Gemini 格式，消耗胖虎AI额度。与其他 Agent 相同，未完成配置写入、启动检测、最小中文对话和功能验收矩阵前，不得计入完整配置交付。

## 13. 连接通讯软件独立增值服务

“连接通讯软件”是登录后“配置Agent”模块内的独立增值交付项目，不是基础 Agent 安装配置的一部分，也不是代理中心能力。

命名规则：客户可见名称统一为“连接通讯软件”。全链路命名统一为“连接通讯软件”，接口路径、字段、表名、事件名和客户文案都使用新的命名口径。

客户可见说明：

```text
把已配置好的 Agent 接入微信、飞书等通讯软件，手机或电脑端都可以在聊天窗口里发送任务、查看回复。
```

产品规则：

- 基础 Agent 配置和连接通讯软件是两个服务，分别下单、分别配置、分别验收、分别收费。
- 基础 Agent 安装配置已通过最小中文对话后，可以完成基础交付；连接通讯软件未接通，不得回滚基础交付。
- 连接通讯软件失败只影响该增值服务，不影响基础 Agent 配置服务。
- 连接通讯软件入口不能要求“本工具本次基础配置会话已完成”才可点击。买家电脑已有可用 Agent 时，应提供选择已有 Agent、检测运行状态、选择通道和单独验收的入口。
- 如果无法自动确认已有 Agent 是否可用，可以进入人工复核或引导先做运行检测；不能把入口完全隐藏。
- 平台支持状态、价格、次数、可售状态和验收策略由服务端下发；客户端不得本地写死。

连接通讯软件验收必须形成独立验收记录。推荐闭环：

1. 选择 Agent：可来自本次基础交付、历史订单、已有本机 Agent 检测或人工复核。
2. 选择平台：QQ Bot、微信、飞书、钉钉、企业微信等，以服务端配置为准。
3. 通过服务端平台授权会话配置机器人或消息通道：客户端发起授权，服务端返回授权链接或二维码，买家在手机/通讯软件中扫码或确认授权，服务端回填平台账号、聊天对象和网关模式。
4. 通讯软件聊天窗口（手机或电脑端）发送指定测试消息。
5. 服务端记录入站平台消息 ID、Agent 调用证据和出站平台消息 ID。
6. 同一通讯软件聊天窗口收到 Agent 回复。
7. 生成连接通讯软件交付验收记录。

防止买家卡扣费漏洞：

- 连接通讯软件交付不能只以“当前能不能收到消息”这个实时状态判断。
- 如果配置已经完成并形成验收证据，客户随后断网、禁用 API Key、取消平台授权、关闭机器人、删除群聊或阻断回调，只能进入暂停、重试或人工复核，不得自动判定为配置失败、自动退款或不收费。
- 如果配置过程中从未形成入站消息、Agent 调用和出站回复证据，则不得标记连接通讯软件交付完成。
- 服务端必须用不可重复的 `source_event_id` 和验收记录防止重复扣费、重复返佣或通过重复回调伪造交付。
- 基础 Agent 配置交付事件和连接通讯软件交付事件必须分开：基础配置使用 `agent_install_delivered`，连接通讯软件使用 `communication_software_link_delivered`；两者不得互相复用。

平台口径：

| 平台 | 文档口径 |
| --- | --- |
| 飞书 | 适合正式机器人接入，可做事件订阅和消息回复 |
| 钉钉 | 适合企业群机器人或 Stream 模式接入 |
| QQ Bot | 适合 QQ 群或频道机器人接入 |
| 企业微信 | 适合企业客户自建应用或群机器人场景 |
| 微信 | 只能按官方或已明确支持的通道说明，不能承诺普通个人微信号稳定接入 |

平台授权规则：

- 买家点击一键连接时，客户端不得要求买家手动填写机器人密钥、个人微信密码、平台 access token 或长期授权密钥。
- 若尚无平台账号或聊天对象，客户端必须先向服务端创建平台授权会话，打开服务端返回的授权链接或二维码页面，再轮询服务端授权结果。
- 授权完成后，平台账号、聊天对象和网关模式由服务端回填到客户端；客户端一键连接只能继续创建配置会话、发起测试和生成本地预检字段，不能自动提交或声明真实验收完成。真实验收必须以通讯软件平台回调、Agent 调用证据、出站回复和服务端验收记录为准。
- 如果平台不支持自动授权或买家未完成扫码/确认，只能进入等待授权、人工复核或失败状态，不能把未授权通道包装成已接通。

日志 / 诊断 / 最近活动能力不是主界面视觉核心，不强制固定在底部，也不强制命名为 Execution Trace Log。Gemini / agy 可以设计为底部面板、侧边抽屉、活动流、可展开诊断区或其他更合适的形式。

规则：

- 未登录闸口不应抢主视觉

## 15. Codex 三种配置模式

Codex 的配置模式只讨论 Codex 自己的 `config.toml` 和 `auth.json`，不能把胖虎AI网站账号混进 Codex 登录。

胖虎AI账号的职责：

- 登录本工具。
- 登录胖虎AI网站。
- 获取服务端授权、权益、API Key、充值购买和代理中心信息。
- 不能登录 Codex。

Codex 当前固定支持三种模式：

1. 普通模式
2. 双态模式
3. 官方直登

普通模式：

- 默认给普通客户使用。
- Codex 走胖虎AI中转站 API。
- 客户填写胖虎AI API Key。
- 消耗胖虎AI中转站额度。
- 不需要登录 ChatGPT 账号。

双态模式：

- 只给需要保留 ChatGPT 登录态，同时仍消耗胖虎AI中转站额度的客户使用。
- 客户自己的 ChatGPT 账号只提供登录态。
- 模型请求仍走胖虎AI API Key。
- 消耗的是胖虎AI额度，不是 ChatGPT 账号额度。
- 本工具不代替客户登录 ChatGPT，不保存 ChatGPT 账号密码。

官方直登：

- 只给明确要使用自己 ChatGPT 账号额度的客户使用。
- Codex 走官方账号登录态。
- 不写入胖虎AI中转站 Key。
- 不消耗胖虎AI中转站额度。
- 如果客户本机没有 ChatGPT 登录态，必须在 Codex 内自行登录 ChatGPT 账号。

客户可见按钮口径：

- “一键部署（普通）”：安装所选 Agent，并写入胖虎AI普通 API 配置。
- “仅修复 Codex 配置”：不重装 Agent，只重新写入普通模式配置。
- “双态配置”：保留 ChatGPT 登录态，但模型消耗走胖虎AI API Key。
- “官方直登”：切换成使用客户自己的 ChatGPT 账号额度。
- “恢复最近备份”：配置异常时退回本次写入前状态。

所有 Codex 模式切换都必须提示：

```text
配置写完后，必须完全退出 Codex，再重新打开 Codex，新的配置才会生效。
```

产品层必须明确：模式切换会先保存当前 Codex 配置快照，再写入目标模式；登录态和客户配置不能因为切换模式被随意覆盖。

## 16. 审计与安全文案固定要求

界面和验收中必须明确表达：

- API Key 不输出到日志
- 保留胖虎AI买家会话 cookie 和内置浏览器 profile，重启后优先自动恢复本工具和胖虎AI网站登录态
- 胖虎AI买家登录密码只有在用户显式勾选“记住密码”时才允许用本机系统加密保存；不得保存明文密码；未勾选时只保存账号提示
- 自动登录只能基于用户显式勾选、可解密的本机加密密码记录和仍有效的买家会话触发
- 内置 WebView 只能拿到账号历史、记住密码标记、自动登录标记和“是否存在已保存密码”；不得一次性接收全部账号的明文密码，自动登录必须由后端按选中账号本机解密后提交
- 不保存第三方账号密码、部署授权 token、订单号、权益 ID 或配置会话 ID
- `profile.json` 只保存账号提示、API Key、模型和界面偏好；买家会话只能保存在独立会话文件和内置浏览器 profile 中
- 胖虎AI网站入口优先复用保存的买家会话；会话被服务端判定失效或用户主动退出时才回到登录门禁
- 所有请求走公共域名 `https://aitokenapi.cc`
- 未通过功能验收矩阵不得包装成完整交付
- 注册、邀请码、创建 Key、充值购买、代理中心和返佣规则都走胖虎AI网站服务端或工具代理后端
- 本地客户端不得硬编码价格、次数、token 返佣、激活返佣、安装返佣、套餐、有效期或设备数
- 连接通讯软件不得和基础 Agent 配置共用验收状态、扣费事件或退款判断；已形成验收证据后，客户断网、禁 Key、取消平台授权或阻断回调不得自动变成配置失败
- 胖虎AI账号不是 Codex 登录账号
- 普通模式和双态模式消耗胖虎AI中转站额度
- 官方直登消耗客户自己的 ChatGPT 账号额度

## 17. 当前允许冻结的部分

当前可以冻结，不应再大改的部分：

- 登录闸口 vs 登录后主控制台的分层方向
- 登录后必须覆盖品牌账号、业务入口、任务流程、主工作区、权益/交付状态、执行日志或诊断能力；具体排版不再固定
- 一级业务入口覆盖：配置Agent、胖虎AI网站、增值业务、代理中心；入口形态由 Gemini / agy 决定
- 模块内步骤导航、主工作区、状态摘要和日志诊断能力必须存在，但可以被 Gemini / agy 重组为侧栏、顶部导航、抽屉、底部面板、命令区或其他更好看的结构
- Gemini / agy 按 `gemini-style-frontend-design` 输出并经截图验收后的视觉方向
- 视觉方向不再锁定为浅色商业控制台或苹果风钛金白路线
- 代理身份只作为登录后账号权益展示
- 代理中心是独立代理业务模块，覆盖 token 返佣、下游付费激活返佣、付费安装 Agent 返佣和工具代理后端，不等同于网站推广返佣页
- 代理业务管理属于胖虎AI管理员后台配置入口，不属于桌面端本地规则入口
- 公开招商页为 `/agent/join`，文案、费用、审核、结算和风险边界由服务端维护
- 注册、邀请码、创建 Key、充值购买、代理中心走内置浏览器 / 网站服务端 / 工具代理后端
- 连接通讯软件固定为“配置Agent”模块内的独立增值交付入口；增值业务只做销售介绍，代理中心不承载该配置入口
- Codex 普通模式、双态模式、官方直登三模式口径
