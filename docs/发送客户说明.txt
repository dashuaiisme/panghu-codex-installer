胖虎AI多 Agent 一键部署工具 - Windows / Mac 客户版

发送给客户：
1. 优先发送二维码图片：docs\多Agent一键配置工具下载二维码.png
2. 客户扫码进入下载页后，按自己的电脑系统选择 Windows 版、Mac Apple 芯片版或 Mac Intel 版。
3. 如果平台不允许发链接，不要公开贴明文下载链接，直接发二维码图片。
4. 如果客户扫码失败，再私下发送统一下载入口：https://aitokenapi.cc/deployer/download
5. 如果需要手动转发文件，Windows 客户发送 胖虎AI多Agent一键部署工具-Windows.zip；Mac 客户先确认芯片类型，M1/M2/M3/M4 等 Apple 芯片发送 胖虎AI多Agent一键部署工具-Mac-AppleSilicon.zip，Intel Mac 发送 胖虎AI多Agent一键部署工具-Mac-Intel.zip。

客户使用：
1. 解压 zip。
2. Windows 打开 胖虎AI多Agent一键部署工具 文件夹，双击 胖虎AI多Agent一键部署工具.exe。
3. Mac 双击 胖虎AI多Agent一键部署工具.app；当前 Mac 包未做 Apple Developer ID 公证。如果系统提示无法验证开发者、已损坏或无法打开，先确认客户下载的是对应芯片版本，再按 macOS 安全提示自行处理。
4. 先用胖虎AI注册账号登录软件；没有账号就点击“去胖虎AI注册账号”。该登录模式无需 ChatGPT 账号。
5. 登录后软件会自动向胖虎AI服务端申请部署授权，未授权账号不能继续部署。
6. 登录后可在“胖虎AI网站”模块内打开控制台、创建 API Key、充值购买、推广返佣和代理中心等服务端页面；内置浏览器会优先复用本次工具会话。如果当前环境无法加载内置浏览器或无法桥接会话，软件会明确阻断并提示内置浏览器未完成/不可用，不会自动打开系统浏览器，且不能算完成内嵌网页闭环。
7. 第一步：打开 API Key 创建页面，创建 Key 后粘贴到工具里，点击“保存并测试 Key”。新注册账号需要先充值或确保账户有余额，否则 Key 可能无法通过测试。
8. 第二步：选择当前电脑系统，点击“检测环境”。如果提示发现 ccswitch、codex++、CCR 等第三方配置插件，请先卸载或禁用。
9. 第三步：选择需要安装的 Agent，并选择 CLI 或客户端入口。
10. 第四步：普通客户点击“一键部署（普通）”。
11. 如果软件提示已临时打开 OpenAI 官网访问窗口，请在 10 分钟内完成 Codex / OpenAI 官方页面访问或登录；到点后会自动关闭并恢复电脑原网络设置。Mac 客户机可能会弹出系统管理员授权提示，这是为了临时写入并到点恢复系统自动代理。
12. 如果 Agent 已经安装过，只是 Codex 配置坏了，点击“仅修复 Codex 配置”，不会重新安装 Agent。
13. 如果客户需要同时保持 ChatGPT 登录态并消耗胖虎AI API Key，点击“双态配置”；不需要这个能力的客户不要点双态模式。
14. 如果客户想让 Codex 消耗自己 ChatGPT 账号里的额度，点击“官方直登”。官方直登不走胖虎AI中转站 Key；如果 Codex 还没登录 ChatGPT 账号，需要客户重开 Codex 后自己登录。
15. Codex 配置写完后，请先完全退出 Codex，再重新打开 Codex；只有完全退出后重新打开，新的配置才会生效。普通模式、双态模式、官方直登都需要重开 Codex。
16. 登录成功后软件会自动检查新版。如果提示有新版本，客户点击“立即更新”后，软件会按当前系统和 Mac 芯片类型下载新版包，自动退出、覆盖程序目录并重新打开新版。客户也可以手动点击“检查更新”，走同样的在线更新流程。
17. 如果需要“手机控制Agent”，请在登录后进入“配置Agent -> 手机控制Agent”。这是独立增值服务，用来把已可用 Agent 接入 QQ、微信、飞书、钉钉、企业微信等手机通讯或办公通道。客户电脑原本已经有可用 Agent 时，也可以先检测已有 Agent，再单独配置手机通道；不要求一定重新安装一次基础 Agent。

按钮说明：
- 一键部署（普通）：普通模式，第一次给客户电脑安装 Agent 时使用，会安装所选 Agent，并应用直接 API 配置。
- 双态配置：额外模式，只给需要“ChatGPT 登录态 + 胖虎AI API Key 消耗”的客户使用，不安装 Agent。
- 仅修复 Codex 配置：普通模式，Agent 已经装好了，但 Codex 配置坏了、换 Key 了、接口不对时使用；不会重新安装 Agent。修复后必须完全退出 Codex 再重新打开。
- 官方直登：切换为客户自己的 ChatGPT 账号额度，不写入胖虎AI中转站 Key；如 Codex 未登录，需要客户重开 Codex 后登录自己的 ChatGPT 账号。
- 恢复最近备份：本次配置后异常，想退回写入前状态时使用。
- 检查更新：下载新版工具包，关闭旧工具后解压覆盖。
- 在线更新只覆盖工具本体，不会清空客户本机保存的账号提示、用户显式保存的本机加密密码记录、API Key、买家会话、内置浏览器资料、Codex 配置或工作区资料；胖虎AI网站入口优先复用保存的买家会话，会话失效时按登录门禁处理。
- 复制日志：出问题时发给客服排查。
- OpenAI 官网临时访问窗口：只在你的账号被临时授权时出现；默认 10 分钟后自动关闭，不需要客户手动改网络；Mac 会按系统要求请求管理员授权。

当前支持的 Agent：
- Codex：可安装和自动配置胖虎AI API Key、接口、模型、中文规则和默认工作区，并通过胖虎AI网关真实任务验证。
- ClaudeCode：覆盖官方 CLI 和客户端入口；写入胖虎AI网关、Key 和模型，并用最小中文对话命令验收。是否能完整交付以客户机器上的检测和功能验收矩阵为准。
- OpenClaw：覆盖官方 CLI 和 Hub/客户端入口；写入 OpenAI-compatible 胖虎AI网关配置，并用最小中文对话命令验收。未检测到 CLI 或最小对话失败时不能算完整交付。
- Hermes：覆盖官方 CLI 和客户端入口；写入胖虎AI网关配置和环境密钥，并用最小中文对话命令验收。是否能完整交付以客户机器上的检测和功能验收矩阵为准。
- Gemini / agy：当前只保留 Google Antigravity 官方入口和待接入状态；暂不写入胖虎AI API Key 或网关配置，不计完整配置交付。
- VS Code / IDE 插件形态不处理；OpenClaw、Hermes 等第三方通道默认跳过。
- 是否完整交付以工具生成的“功能验收矩阵”为准；安装、配置写入、启动检测、最小对话未全部通过时，不扣次、不算完整交付。
- 手机控制Agent单独收费、单独验收；基础 Agent 能正常对话后，基础配置服务可以独立完成。手机控制Agent未接通，只处理手机控制Agent这一项，不影响已经验收的基础 Agent 配置。手机控制Agent配置完成并形成验收证据后，如果客户自行断网、禁用 Key、取消平台授权、关闭机器人或删除群聊，不会自动当成配置失败或免单。

注意：
- 工具默认使用公开客户域名 https://aitokenapi.cc。
- 软件里的“接口地址”只做展示，客户不能编辑；配置和测试都会固定使用 https://aitokenapi.cc。
- 该配置方式无需登录 ChatGPT 账号，也可以正常使用 Codex。
- 胖虎AI账号只用于登录本工具和胖虎AI网站，不能登录 Codex；Codex 官方直登登录的是客户自己的 ChatGPT 账号。
- 强安全版依赖胖虎AI服务端的 /api/deployer/activate 和 /api/deployer/manifest 接口；后端没上线前，新包会在授权阶段停止。
- 如果工具提示发现第三方配置插件，必须先处理后再安装；这些工具可能把 Codex / ClaudeCode 配置改坏，导致后续使用异常。
- 不要把内部接口、私有域名或上游管理域名发给客户。
- Windows 不要只单独发送 exe，必须连同 _internal 文件夹一起发送。
- Mac 不要从 .app 里单独抽文件发送，直接发送完整 zip；Apple 芯片和 Intel 芯片不能混发。
- 如果 Windows 要单文件 exe，后续可以改 PyInstaller 参数为 --onefile。
- 本工具只调用官方安装入口，不内置、不修改、不伪装第三方 Agent 本体。
- 出问题时点击“复制日志”，把日志发回来排查。
- 如果客户配置后想退回写入前状态，可以点击“恢复最近备份”。
- Codex 会写入 ~/.codex/config.toml 和 ~/.codex/auth.json。普通模式和双态模式使用 panghuAI 中转配置，接口为 https://aitokenapi.cc/v1；官方直登使用官方 openai provider。
- Codex 默认使用普通直接 API 配置，消耗胖虎AI中转站额度。点击“双态配置”后，登录态来自客户自己的 ChatGPT 账号，但模型调用仍消耗胖虎AI API Key。点击“官方直登”后，模型请求消耗客户自己的 ChatGPT 账号额度。本工具不代替登录，也不保存 ChatGPT 账号密码。
- 工具会在模式切换前保存当前 Codex 配置快照，避免登录态和配置被切换模式弄乱。
- 临时访问窗口只用于短时间访问 OpenAI / Codex 官方页面，不会让客户长期使用你的代理；工具不会接收或保存客户 OpenAI 官网账号密码。
- 代理中心、邀请码、返佣、充值购买和套餐规则均以胖虎AI网站服务端或工具代理后端为准，客户端只提供入口和状态提示，不在本地计算或写死规则。代理中心后续会区分 token 返佣、下游付费激活返佣和付费安装 Agent 返佣；未看到服务端返回前，不能把这些状态说成已完成。

Codex 官方离线包可选说明（Windows）：
- 如果客户电脑 Microsoft Store 下载失败，可以把官方签名的 Codex 离线安装包放到工具目录的 offline 文件夹里。
- 支持的旁挂文件类型：.msixbundle、.msix、.appx、.appxbundle、.appinstaller。
- 工具会校验离线包的 Windows 签名；签名无效或来源不明的文件不会安装。
- 不要把非官方、改过名但来源不明的 Codex 文件放进去。
