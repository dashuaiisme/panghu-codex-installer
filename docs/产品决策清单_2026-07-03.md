## 一、代理业务

### 1.1 等级与开通费用
✅ 决定：每级价格、有效期、审核策略全部由管理员后台可视化设置（不写死）。后台默认值采用建议方案：L1 免费自动开通，L2-L3 收费自动开通，L4-L5 收费+人工审核，年费制；具体金额上线前在后台填写。

### 1.2 三类佣金比例
✅ 决定：
- token 返佣：默认 1层10% / 2层5% / 3层3% / 4层2% / 5层1%，管理员后台可改。
- 下游付费激活返佣：按订单金额百分比，各层比例管理员后台设置。
- 付费安装 Agent 返佣：各层比例管理员后台设置。
- 三类佣金同一笔消费不叠加（事件类型互斥）。
- 全局规则 + 后台可对单个代理覆盖。

### 1.3 结算与提现
✅ 决定：结算周期 T+30（佣金产生 30 天后 pending → available，期内退款可冲正）；最低提现 500 元；提现方式仅支付宝；提现全部人工审核。

### 1.4 归因与风控
✅ 决定：邀请码 + 专属链接双通道归因；注册时绑定上级，永久不可更换；自邀/刷单先人工判定（后台提供冻结/解冻/冲正操作）；招商页文案由 Claude 起草（见 `docs/代理招商页文案草稿.md`）。

### 1.5 管理后台开发
✅ 决定：由 Claude 开发（独立服务端项目）。做好并验收前，代理中心相关功能不上线；客户端代理中心保持"待接入"展示。
